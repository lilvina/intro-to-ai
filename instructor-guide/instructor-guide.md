# Instructor Guide
## Intro to Building with AI APIs

Author: Davina Taylor
Role: Technical Curriculum Developer | Software Engineering Educator

---

# Course Overview

## Course Description

This course introduces learners to the fundamentals of building applications using AI APIs. Through hands-on coding exercises, prompt experimention, and project-based learning, learners progress from understanding APIs to building a functional AI-powered application.

The course emphasizes:
- Applied learning
- Iteration and experimentation
- Real-world AI workflows
- Enterprise AI concepts
- Responsible AI practices

---

# Target Audience

This course is designed for:
- Beginner to intermediate developers
- Learners new to AI APIs
- Students with basic Python knowledge
- Developers interested in integrating AI into applications

---

# Learning Outcomes

By the end of the course, learners will be able to:
- Explain how AI APIs work
- Explain how AI APIs are different from traditional APIs
- Make authenticated AI API requests
- Design and improve prompts
- Build AI-powered application features
- Evaluate AI-generated outputs critically
- Handle API and output-related errors

---

# Teaching Philosophy

This course uses a hands-on, project-based learning approach.

Learners are encourage to:
- Experiment frequently
- Iterate on prompts
- Learn through debugging
- Focus on building usable features

The instructor should reinforce that:
- AI outputs are not always correct
- Iteration is a core skill
- Clear prompts improve results
- AI systems require human oversight

# MODULE 1 - COURSE INTRODUCTION

## Learning Goals
Help learners understand:
- Course expectations
- What AI APIs are & why they matter
- Real-world AI use cases

---

## Key Teaching Points

Emphasize:
- AI APIs are tools developers can integrate into applications
- AI APIs are increasingly used in enterprise workflows
- Developers can build AI-powered features without training models from scratch

---

## Discussion Prompt

> "What products or applications do you think already use AI APIs?"

---

## Common Learner Challenges

- Feeling intimidated by AI terminology
- Confusing AI APIs with machine learning model training
- Thinking AI developement requires advanced math

---

## Teaching Tips

- Reassure learners that this course focuses on practical implementation
- Use real-world examples frequently
- Emphasize experimentation over perfection

---

# MODULE 2 - API BASICS

## Learning Goals

Help learners:
- Understand request/response flow
- Read JSON data
- Understand how systems communicate

---

## Key Teaching Points

Explain:
- API = Application Programming Interface
- APIs allow systems to exchange information
- APIs commonly return JSON

---

## Analogy

Use the "restaurant waiter" analogy:
- Client = customer
- API = waiter
- Server = kitchen

---

> "What apps on your phone likely use APIs?"

---

## Common Learner Challenges

- Confusing APIs with databases
- Difficulty understanding JSON formatting
- Understanding request vs response

---

## Teaching Tips

- Walk through examples slowly
- Show API responses visually
- Explain terminology repeatedly

---

# MODULE 3 - FIRST AI API CALL

## Learning Goals

Help learners:
- Authenticate API requests
- Send prompts
- Read AI-generated responses

---

## Key Teaching Points

Explain:
- API keys authenticate requests
- Prompts shape outputs
- AI APIs generate responses dynamically

---

## Discussion Prompt

> "How is an AI API different from a weather API?"

---

## Common Learner Challenges

- API key setup issues
- Environment variable confusion
- Fear of breaking code

---

## Teaching Tips

- Normalize debugging
- Encourage experimentation with prompts
- Remind learners that outputs may vary

---

# MODULE 4 - PROMPT DESIGN

## Learning Goals

Help learners:
- Write more effective prompts
- Understand prompt structure
- Improve output quality

---

## Prompt Framework

Introduce:
1. Instruction
2. Context
3. Output Format

---

## Example

Weak Prompt:
> "Explain Python"

Strong Prompt:
> "Explain Python to a beginner in 3 bullet points with examples"

---

## Discussion Prompt

> "Why do vague prompts create vague outputs?"

---

## Common Learner Challenges

- Writing prompts that are too broad
- Forgetting formatting instructions
- Not specifying audience

---

## Teaching Tips

- Encourage iteractive refinement
- Compare outputs side-by-side
- Emphasize clarity and specificity

---

# MODULE 5 - BUILDING AN AI FEATURE

## Learning Goals

Help learners:
- Connect prompts to product features
- Build reusable AI functionality
- Think like product developers

---

## Key Teaching Points

Explain:
- AI features combine prompts + code + user input
- Most AI applications follow similar workflows:
Input -> Prompt -> AI -> Output

---

## Discussion Prompt

> "What real-world problem does your feature solve?"

---

## Common Learner Challenges

- Overcomplicating features
- Poor function organization
- Focusing too much on UI instead of functionality

---

## Teaching Tips

- Encourage simple MVPs
- Focus on usability
- Reinforce incremental development

---

# MODULE 6 - ERROR HANDLING + AI EVALUATION

## Learning Goals

Help learners:
- Handle API failures gracefully
- Critically evaluate AI outputs
- Understand AI limitations

---

## Key Teaching Points

Explain:
- AI outputs are not always correct
- Error handling improves user experience
- Human oversight remains important

---

## Discussion Prompt

> "How could incorrect AI output impact real users?"

---

## Common Learner Challenges

- Assuming AI outputs are factual
- Ignoring edge cases
- Weak validation logic

---

## Teaching Tips

- Encourage testing with multiple prompts
- Demonstrate failed outputs intentionally
- Reinforce critical thinking
