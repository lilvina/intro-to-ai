# Intro to Building with AI APIs

This project is a beginner-friendly curriculum designed to teach developers how to build applications using AI APIs through hands-on, project-based learning.

---

## Course Overview

This course introduces learners to:
- API fundamentals
- AI API integration
- Prompt engineering basics
- Building AI-powered application features
- Evaluating and improving AI outputs

The course combines instructional content, hands-on coding exercises, assessments, and a final project.

## Lessons
1. API Basics
2. First AI API Call
3. Prompt Design
4. Build a Feature
5. Error Handling

## Final Project
Build a working AI-powered CLI application.

## Tech Stack
- Python
- OpenAI API
- Requests
- python-dotenv

Also, make sure to add a .gitignore file for your .env so your API keys won't be exposed to the public!

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/lilvina/intro-to-ai
```

### 2. Install Dependencies
```bash
pip3 install -r requirements.txt
```

### 3. Create a .env File
```bash
OPENAI_API_KEY=your_api_key_here
```

### 4. Run a Lesson
```bash
python3 lesson-2-ai-api-call/ai_request.py
```
